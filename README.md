# @agentpay/agent-memory-mcp

Persistent key-value memory for AI agents

This npm package wraps the Python MCP server at [Rumblingb/agent-memory-mcp](https://github.com/Rumblingb/agent-memory-mcp).

## Install

```bash
npm install -g @agentpay/agent-memory-mcp
pip install mcp
```


## Usage

```json
{
  "mcpServers": {
    "agent-memory-mcp": {
      "command": "npx",
      "args": ["@agentpay/agent-memory-mcp"]
    }
  }
}
```
